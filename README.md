# Lidarr on StartOS

[Lidarr](https://github.com/Lidarr/Lidarr) is a music collection manager for Usenet and BitTorrent users. This repository packages Lidarr for StartOS, following the shared-storage and optional qBittorrent integration used by Sonarr.

- Upstream: <https://github.com/Lidarr/Lidarr>
- Package: <https://github.com/Start9Labs/lidarr-startos>
